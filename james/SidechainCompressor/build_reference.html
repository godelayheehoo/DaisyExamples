What this is

A desktop stereo compressor with sidechain input, built around an Electrosmith Daisy Seed DSP module. A kick drum signal plugged into the sidechain input drives the compression envelope, causing the stereo audio to duck in time with the kick — the classic pumping effect. The unit also includes selectable character modes (soft saturation, wavefolding, or full ducker mode) and a stereo width control.

All signal processing happens in software on the Daisy Seed. The only analog circuitry required is a small input conditioning stage for the sidechain channel.

NOTE: I have moved to a pcb-based build since this, this is kept for historical purposes.

Signal flow

Stereo audio path

Left and right audio inputs connect directly to the Daisy Seed's audio codec pins. The Seed processes the stereo pair — applying gain reduction driven by the sidechain envelope, then saturation, then stereo width adjustment — and outputs on the left and right audio output pins. No external components needed in this path.

Sidechain path

The sidechain input cannot connect directly to the Seed's ADC pins, which expect 0–3.3V. The signal passes through a conditioning circuit built around one half of a NE5532 dual op-amp (U1A), configured as a non-inverting amplifier with mid-rail biasing for single-supply operation. The op-amp package's supply pins (and the bias divider) run from a dedicated regulated rail rather than raw barrel-jack voltage — see Power section below.

  • A 100nF cap (C1) blocks any DC offset from the source device
  • Two 100kΩ resistors (R1, R2) form a divider between the regulated 9V_Clean rail and GND, biasing the op-amp's non-inverting input (pin 3) at mid-rail — required for correct single-supply operation
  • A 10kΩ resistor (R3, "Rg") from pin 2 to GND and a 100kΩ resistor (R4, "Rf") from pin 1 to pin 2 set the gain to approximately 11x. Under review — this gain may be reduced (Rf → ~47k or ~33k) if the sidechain input clips with the op-amp running at full regulated voltage; confirm current value against the schematic before building.
  • A second 100nF cap (C2) on the output (pin 1) blocks the mid-rail DC bias before the signal reaches the ADC pin
  • Two bias resistors (~100kΩ each) at the Daisy's ADC input pin (D25) — one to 3.3V_A, one to GND — establish a defined ~1.65V mid-rail reference at the pin itself. Without these, the AC-coupled signal has no defined center point and the ADC reading can rail to one extreme.

In software, the Seed tracks the amplitude of this signal using an envelope follower, and uses that envelope as the control signal for the compressor on the stereo path.

Controls

Eight potentiometers and one three-position toggle switch. Each pot: pin 1 to GND, pin 3 to 3V3_A, wiper (pin 2) to the ADC pin.

Control Daisy pin Range Pot type Function
Threshold A0 / D15 −60 to 0 dB B-type (linear) Level at which compression begins. Firmware maps linearly to dB, which is itself a log scale — so a linear pot gives perceptually even spacing across the dB range.
Ratio A1 / D16 1:1 to 100:1, then 1:inf past 90% B-type (linear) How aggressively gain is reduced above threshold. Past 90% pot travel, acts as 1:inf brickwall limiting. Firmware applies powf(100, x) — exponential mapping done in code, so a linear pot spreads the range correctly.
Attack A2 / D17 0.2ms to 150ms A-type (audio/log) How quickly compression engages after threshold is crossed. Firmware maps linearly (0.2–150ms), but time constants are heard logarithmically. An A-type pot gives better feel: most travel in the musically useful 1–30ms range.
Release A3 / D18 0.2ms to 500ms A-type (audio/log) How quickly compression releases after signal falls below threshold. Same reasoning as Attack — linear firmware mapping over a wide time range benefits from a log-taper pot.
Mix A4 / D19 0 to 100% B-type (linear) Blend between dry (uncompressed) and wet (compressed) signal. Linear blend, linear pot — no transformation needed.
Drive A5 / D20 0 to 100% A-type (audio/log) Amount of saturation applied after compression (controls Ducking Depth from 0 to −100 dB in Ducker mode). Saturation depth is perceived logarithmically; an A-type pot gives finer control in the subtle 0–30% range.
Character Switch D26 + D27 3 Positions — Selects character mode: Soft Saturation / Ducker Mode / Wavefolding
Width A7 / D22 0 to 200% B-type (linear) Stereo width. 100% = unchanged. Below narrows, above widens. Linear mapping in firmware; a linear pot puts center (100%) at 12 o'clock which is the natural expectation.
Output A8 / D23 0 to +24 dB A-type (audio/log) Final output makeup gain trim. Firmware maps linearly to dB (0–24 dB), but gain is heard logarithmically — an A-type pot concentrates travel in the 0–12 dB range most commonly used.
SC Filter Cutoff A6 / D21 20Hz to 20kHz B-type (linear) Cutoff frequency of the sidechain filter. Firmware applies 20 × powf(1000, x) — a full decade-per-division exponential sweep done in code. A linear pot is correct; the log sweep is handled entirely by the firmware.
SC Filter Type D11 + D12 LPF / BPF / HPF — Filter mode applied to sidechain signal. Center position = BPF.
Footswitch D13 On / Off — Latching bypass switch. Engaged = effect active, disengaged = clean pass-through.
Footswitch LED D14 On / Off — Indicates effect status. Solid on when engaged, off when bypassed.
Bootloader Entry D8 Logic Low — Hold at boot to enter bootloader mode
Ramp Rate Pot A9 / D24 0.02–8 Hz (exp) B-type (linear) LFO rate for the ramp / LFO auto-mapping system. Firmware applies 0.02 × powf(400, x) — exponential rate mapping in code. Linear pot is correct. Wired same as all other pots (3V3_A / wiper / GND).
Ramp Button D10 Momentary, active-LOW — Triggers the LFO learn gesture. One leg to D10, other leg to GND. Internal pull-up enabled in firmware.
Ramp LED D9 Output — Learn-mode and pot-override indicator. See wiring below. Starts OFF at boot.

The three-position toggle switch selects the processing character. Two signal legs connect to D26 and D27. Configure both with internal pull-ups in firmware. The three positions select: soft clip (smooth, tape-like), ducker mode (fully ducks output when sidechain triggers), or wavefold (complex, synth-like).

Complete wiring summary

Audio input (stereo TRS)

One 1/4" TRS jack. Tip → AUDIO IN L. Ring → AUDIO IN R. Sleeve → GND.

Audio output (stereo TRS)

One 1/4" TRS jack. Tip → AUDIO OUT L. Ring → AUDIO OUT R. Sleeve → GND.

Sidechain input

One 1/4" TS jack. Full signal chain:

  • Jack tip → one leg of C1 (100nF, DC blocking)
  • Other leg of C1 → pin 3 of U1A (NE5532)
  • Pin 3 also connects to the junction of R1 and R2 (100kΩ each) in series between 9V_Clean and GND — this biases pin 3 at mid-rail
  • Pin 2 → Rg1 (10kΩ) → GND (gain-setting resistor)
  • Pin 1 → Rf1 (47kΩ) → pin 2 (feedback resistor)
  • Pin 1 → C2 (100nF) → A10 / D25 on Daisy Seed (DC blocking on output)
  • At D25: R4 (100kΩ) to 3.3V_A and R3 (100kΩ) to GND, to stiffen the pin with a defined mid-rail reference
  • Pin 8 (V+) → 9V_Clean. Pin 4 (V-/GND) → GND. Note: pins 8/4 are the physical supply pins for the whole NE5532 package — both op-amp halves (U1A and U1B) share them, even though schematic tools draw them on one "unit" of the symbol.
  • Jack sleeve → GND
Component summary: 2× 100nF ceramic cap (C1, C2), 2× 100kΩ resistor (R1/R2, bias divider), 1× 47kΩ resistor (Rf1, feedback), 1× 10kΩ resistor (Rg1, gain), 2× 100kΩ resistor (R3/R4, D25 bias pair), 1× NE5532P DIP-8 (dual op-amp; second half, U1B, configured as a unity-gain follower — see below — no additional passives required).

Unused op-amp half (U1B)

The NE5532 is a dual op-amp; only one half (U1A) is used for sidechain conditioning. Leaving the second half's inputs floating risks unpredictable current draw or oscillation, which can inject noise into the shared supply pins (8/4) used by both halves. Configure U1B as a unity-gain voltage follower referenced to the existing mid-rail bias node, using no additional components:

  • Pin 5 (IN+) → the same R1/R2 mid-rail bias node already feeding U1A's pin 3
  • Pin 7 (OUT) → pin 6 (IN−) — direct wire, closes the feedback loop as a voltage follower
  • Pin 7 output is otherwise left unconnected — not used anywhere else in the circuit
In KiCad: place the NE5532P symbol's second unit under the same reference designator (U1) rather than as a separate part — right-click → Edit Properties → Unit selector if it's not already assigned correctly. Confirm pin numbers 5/6/7 against the symbol's unit table before wiring, since some library symbols split units differently. Note: your library's symbol may label this second unit "U1C" rather than the more conventional "U1B" — that's just this symbol's internal unit lettering, not a different physical part; confirm it's still reference U1 (same package) before wiring.

Potentiometers (all 8, wired identically)

Note: If your pots are moving backwards (e.g., CW decreases the value), you have likely swapped GND and 3V3_A. The mapping below reflects a "reversed" wiring fix implemented in software.
  • Pin 1 (left leg / fully CCW) → 3V3_A on Daisy Seed
  • Pin 2 (middle / wiper) → corresponding ADC pin per table above
  • Pin 3 (right leg / fully CW) → GND

Character switch (3-position toggle)

  • Common/center terminal → GND
  • Position 1 terminal → D26 → Soft Clip
  • Position 2 terminal → D27 → Ducker Mode
  • Center position (neither pin grounded) → Wavefold
  • Configure D26 and D27 with internal pull-ups in firmware

Sidechain filter switch

  • Common/center terminal → GND
  • Position 1 terminal → D11 → LPF
  • Position 2 terminal → D12 → HPF
  • Center position (neither pin grounded) → BPF

Footswitch bypass

A latching footswitch controls effect bypass. When engaged (closed), the effect is active and the footswitch LED lights solid. When disengaged (open), audio passes through unprocessed and the LED is off.

  • One lug of the latching footswitch → D13
  • Other lug → GND
  • Configure D13 with internal pull-up in firmware (active-LOW: closed = grounded = engaged)

Footswitch LED

  • D14 → 220Ω resistor → LED anode (long leg)
  • LED cathode (short leg) → GND
  • Solid on when effect is engaged, off when bypassed.

Ramp Button

Momentary push button used for the LFO learn gesture and the clear gesture (Ramp Button + Footswitch tap).

  • One leg → D10
  • Other leg → GND
  • Configure D10 with internal pull-up in firmware (active-LOW: pressed = grounded)

Ramp LED

Indicator for the LFO learn-gesture phases and pot-override triple-flash. Starts OFF at boot (unlike earlier builds where this LED was initialized on).

  • D9 → 220Ω resistor → LED anode (long leg)
  • LED cathode (short leg) → GND

Sidechain activity LED

  • D30 → 220Ω resistor → LED anode (long leg)
  • LED cathode (short leg) → GND
  • LED pulses in time with kick drum when envelope follower exceeds the compression threshold.

Bootloader entry button

Wiring: Connect one side of a momentary push button to D8 (Board Pin 9) and the other side to GND.
  • Usage: Hold the button down while powering on or pressing the Reset button on the Daisy Seed.
  • Function: Triggers the System::ResetToBootloader() routine, allowing for firmware updates without needing to access the physical buttons on the Daisy module itself.

Power

  • Daisy Seed: powered via USB during development. For finished unit, use the VIN pin (accepts 4.5–17V) or regulated 5V on the 5V pin. VIN stays on the raw, unregulated barrel-jack rail — do not route it through the LDO below.
  • Barrel jack → 1N5819 reverse-polarity protection diode (D1) → raw +9V node. This raw node feeds Daisy VIN directly.
  • LM2940T-9.0 LDO (U2, TO-220): IN ← raw +9V (after D1), GND → common ground, OUT → new 9V_Clean net. This regulated rail feeds the NE5532's supply pins (8/4) and the R1/R2 bias divider — nothing else taps raw +9V for analog use.
  • 100nF ceramic cap from 9V_Clean to GND, right at the LDO's OUT pin (local stability bypass).
  • 100nF decoupling cap between 3V3_A and GND, close to the Seed.
  • 100nF decoupling cap (C4) across the NE5532 supply pins (pin 8 to pin 4), close to the chip.
Rationale: running the op-amp directly off unregulated barrel-jack voltage was the source of an audible whine (barrel jack + sidechain connected = whine; USB power or no sidechain = quiet). The LDO isolates the analog supply from raw barrel-jack noise/ripple. Confirmed to have resolved the whine as of the last build session.

Notes

  • Use 3V3_A (analog 3.3V), not the digital 3V3 pin, as the reference for pot wiring and the D25 bias pair. The analog reference is isolated from digital switching noise.
  • Connect both AGND and DGND pins on the Seed to your ground rail.
  • The mid-rail bias divider (R1/R2 to mid-rail) is required for single-supply operation of the NE5532. Without it the output saturates to a supply rail.
  • The output coupling cap (C2) is required to strip the mid-rail DC bias before the signal reaches the Daisy ADC pin, which must stay within 0–3.3V.
  • The D25 bias pair (R4, 100kΩ to 3.3V_A; R3, 100kΩ to GND) is separately required — without it, the ADC pin itself has no defined center point for the AC-coupled signal to sit on, and readings can rail or "ghost" the previous ADC channel's value.
  • If the sidechain input clips (pre-filter reading pinned near 0 dB, no response to signal) after the LDO is in place, first confirm the D25 bias pair is present; if it still clips, reduce Rf1 ("Rf") from 47kΩ toward 33kΩ or 22kΩ to lower gain.
  • If the source device (e.g. Pocket Operator) has low output level instead, reduce Rg1 ("Rg") to increase gain. Gain = 1 + (Rf1 / Rg1).
  • Op-amp supply noise is the dominant noise source in this architecture — running U1A/U1C directly off unregulated barrel-jack voltage caused an audible whine, resolved by adding the LM2940 LDO on a dedicated 9V_Clean rail feeding only the analog section (not Daisy VIN).
  • U1B (second NE5532 half) is configured as a unity-gain follower off the existing mid-rail bias node (see Unused op-amp half section) rather than left floating — this avoids unpredictable current draw or oscillation that could couple noise into the shared supply pins (8/4).
