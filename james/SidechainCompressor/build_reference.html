What this is

A desktop stereo compressor with sidechain input, built around an Electrosmith Daisy Seed DSP module. A kick drum signal plugged into the sidechain input drives the compression envelope, causing the stereo audio signal to duck in time with the kick — the classic pumping effect. The unit also includes adjustable saturation with three character modes and a stereo width control.

All signal processing happens in software on the Daisy Seed. The only analog circuitry required is a small input conditioning stage for the sidechain channel.

Signal flow

Stereo audio path

Left and right audio inputs connect directly to the Daisy Seed's audio codec pins. The Seed processes the stereo pair — applying gain reduction driven by the sidechain envelope, then saturation, then stereo width adjustment — and outputs on the left and right audio output pins. No external components needed in this path.

Sidechain path

The sidechain input cannot connect directly to the Seed's ADC pins, which expect 0–3.3V. The signal passes through a conditioning circuit built around a TL072 op-amp configured as a non-inverting amplifier with mid-rail biasing for single-supply operation:

  • A 100nF cap blocks any DC offset from the source device
  • Two 100kΩ resistors form a divider between 9V and GND, biasing pin 3 at 4.5V — required for correct single-supply operation
  • A 10kΩ resistor (Rg) from pin 2 to GND and a 100kΩ resistor (Rf) from pin 1 to pin 2 set the gain to approximately 11x
  • A second 100nF cap on the output (pin 1) blocks the 4.5V DC bias before the signal reaches the ADC pin

In software, the Seed tracks the amplitude of this signal using an envelope follower, and uses that envelope as the control signal for the compressor on the stereo path.

Controls

Eight potentiometers and one three-position toggle switch. Each pot: pin 1 to GND, pin 3 to 3V3_A, wiper (pin 2) to the ADC pin.

The three-position toggle switch selects saturation character. Two signal legs connect to D26 and D27. Configure both with internal pull-ups in firmware. The three positions select: soft clip (smooth, tape-like), hard clip (aggressive), or wavefold (complex, synth-like).

Complete wiring summary

Audio input (stereo TRS)

One 1/4" TRS jack. Tip → AUDIO IN L. Ring → AUDIO IN R. Sleeve → GND.

Audio output (stereo TRS)

One 1/4" TRS jack. Tip → AUDIO OUT L. Ring → AUDIO OUT R. Sleeve → GND.

Sidechain input

One 1/4" TS jack. Full signal chain:

  • Jack tip → one leg of 100nF cap (DC blocking)
  • Other leg of cap → pin 3 of TL072
  • Pin 3 also connects to the junction of two 100kΩ resistors in series between 9V and GND — this biases pin 3 at 4.5V (mid-rail)
  • Pin 2 → 10kΩ resistor → GND (this is Rg, sets gain)
  • Pin 1 → 100kΩ resistor → pin 2 (this is Rf, feedback)
  • Pin 1 → 100nF cap → A10 / D25 on Daisy Seed (DC blocking on output)
  • Pin 8 → 9V. Pin 4 → GND
  • Jack sleeve → GND
Component summary: 2× 100nF ceramic cap, 2× 100kΩ resistor (bias divider), 1× 100kΩ resistor (Rf), 1× 10kΩ resistor (Rg), 1× TL072 DIP-8.

Potentiometers (all 8, wired identically)

  • Pin 1 (left leg / fully CCW) → GND
  • Pin 2 (middle / wiper) → corresponding ADC pin per table above
  • Pin 3 (right leg / fully CW) → 3V3_A on Daisy Seed

Saturation switch (3-position toggle)

  • Common/center terminal → GND
  • Position 1 terminal → D26
  • Position 2 terminal → D27
  • Position 3 inferred in software when both D26 and D27 read low
  • Configure D26 and D27 with internal pull-ups in firmware

Sidechain activity LED

  • D30 → 220Ω resistor → LED anode (long leg)
  • LED cathode (short leg) → GND
  • LED pulses in time with kick drum when envelope follower exceeds threshold. Adjust kLedThreshold in firmware if needed.

Power

  • Daisy Seed: powered via USB during development. For finished unit, use the VIN pin (accepts 4.5–17V) or regulated 5V on the 5V pin.
  • TL072: powered from 9V rail. Pin 8 → 9V, Pin 4 → GND.
  • Add 100nF decoupling cap between 3V3_A and GND, close to the Seed.
  • Add 100nF decoupling cap across the TL072 supply pins (pin 8 to pin 4), close to the chip.

Notes

  • Use 3V3_A (analog 3.3V), not the digital 3V3 pin, as the reference for pot wiring. The analog reference is isolated from digital switching noise.
  • Connect both AGND and DGND pins on the Seed to your ground rail.
  • The sidechain conditioning circuit is five passive components plus one op-amp. It fits on a small section of breadboard.
  • The mid-rail bias (two 100kΩ resistors to 4.5V) is required for single-supply operation of the TL072. Without it the output saturates to the supply rail.
  • The output coupling cap (second 100nF after pin 1) is required to strip the 4.5V DC bias before the signal reaches the Daisy ADC pin, which must stay within 0–3.3V.
  • If the source device (e.g. Pocket Operator) has low output level, reduce Rg to increase gain. Gain = 1 + (Rf / Rg). With Rf = 100kΩ and Rg = 2.2kΩ, gain ≈ 46x.
